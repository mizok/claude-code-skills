# claude-code-skills

A collection of skills for [Claude Code](https://claude.ai/code).

## Skills

### claude-code-notifications

Sets up macOS notifications with custom sound and icon for Claude Code hooks.

> **macOS only.** Requires Claude Code and Homebrew.

### micro-interactions

Design-language rules for building interactive UI that feels finished: no layout
shift, interruptible motion, the right spring for the distance, the full gesture
abandonment surface, keyboard parity and reduced-motion support.

> Framework-agnostic. Distilled from [interior.dev](https://www.interior.dev/) (MIT).

```bash
npx skills add mizok/claude-code-skills --skill <skill-name>
```

## Browse all skills

```bash
npx skills add mizok/claude-code-skills --list
```
